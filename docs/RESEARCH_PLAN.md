## 1. 我们究竟要做什么

用 MuJoCo 做一个简单机械臂。让它的末端移动到目标点，再给末端增加重量，观察控制效果是否变差。接着用一些运动数据修正控制器的预测，检查能否改善表现。

研究中心是一句话：

> **面对机械臂负载变化，用少量数据估计重量，还是用神经网络修正运动预测，更值得做？**

**2026-10-15 调整为：**

> **机械臂拿起未知物体后，用数据学出来的模型去规划动作，什么时候比用物理公式估计参数更好，什么时候反而会害了控制？**

调整原因和新的里程碑见 [PLAN](PLAN.md)。下文第 4 节的三种方法仍然是核心，另加两种（C3 混合、C2-E 集成），并加入质心偏移和关节摩擦两种模型误差。

“负载”就是末端带着的重量。“运动预测”就是根据现在的位置、速度和施加的力，预测下一刻机械臂会在哪里。这里先在仿真里附加质量，不涉及抓取物体的接触过程。

这是一项机器人控制与机器学习结合的研究准备项目。不是做通用机器人，不要求先读懂十篇最新论文，也不预先承诺神经网络一定更好。

## 2. 简单到什么程度，困难在哪里

第一版只做**两个关节、两根连杆、在竖直平面里运动的机械臂**，类似肩膀和肘部。保留重力，所以末端增加重量会影响受力。先到达目标，再考虑沿一段轨迹移动。

| 环节 | 难度判断 | 为什么这样安排 |
|---|---|---|
| 显示机械臂、改变关节角度 | 入门可做 | 先认识身体结构和运动，尽早看见结果 |
| 用简单控制器到达目标 | 需要补控制基础，但范围可控 | 理解位置误差、速度与力矩；力矩就是让关节转动的作用 |
| 建立运动模型、实现 MPC | 核心学习难点 | MPC 会向前预测一段运动，选择动作，执行一步后重新计算 |
| 用数据估计负载、训练小网络 | 中等难度 | 学会数据采集、拟合与独立测试 |
| 做公平实验并解释结果 | 研究工作的重点 | 排除调参、数据泄漏和额外计算量带来的假优势 |

MuJoCo 本身不是最难的部分。第一版不用七关节 Panda、相机、语言模型、抓取和复杂接触。小型 CPU 仿真与小网络是设计目标，实际速度需要安装后测量，不预先保证实时运行。

## 3. 先看见，再解释，最后加算法

每次推进一个能观察到的变化，按下面顺序做：

1. **认识机械臂。** 看到两根连杆、两个关节和目标点；改一个角度，观察末端怎么动。此时只是运动展示，不算控制实验。
2. **让机械臂自己到达目标。** 使用简单的 PD 控制：位置偏差决定往哪边用力，速度反馈帮助避免晃动。观察目标点和真实末端之间的误差。
3. **引入 MPC。** 用模型预测几步后的运动，选择一段动作，但只执行第一步，然后根据新状态再计算。先空载跑通，再改变重量；不同时加入神经网络。
4. **看模型哪里错了。** 对比预测位置与实际位置。加重量后未必明显变差，先检查控制器的补偿能力、任务速度和力矩限制；不为了漂亮结果故意削弱基线。
5. **比较两种修正。** 相同运动数据分别用于估计负载重量、训练预测误差的小网络，再接回同一个 MPC。
6. **独立检验。** 在未用于训练的目标/轨迹上比较控制效果、所需数据量和运行时间，解释哪些场景没有改善。

每一步都应能暂停、慢放和重新运行。画面至少显示目标点、末端轨迹、控制方法、仿真时间和末端误差；后续增加“模型预测轨迹 vs 实际轨迹”。实验条件和随机种子保持可重放。

画面的播放速度和控制算法的计算速度分开显示。慢慢算完再流畅回放，不能称为实时控制。可视化用来理解，最终结论仍依靠多次实验数据。

## 4. 三种方法，共用一个控制器

| 方法 | 修改的内容 | 回答的问题 |
|---|---|---|
| C0：原模型＋MPC | 使用未更新的空载参数 | 原控制器在重量变化后能做到什么程度？ |
| C1：估计重量＋MPC | 从运动数据估计一个负载参数，更新模型 | 一个简单、可解释的修正是否已经足够？ |
| C2：误差学习＋MPC | 小网络预测原模型漏掉的运动变化 | 更灵活的修正是否值得额外的训练与计算？ |

可用的网络输入是关节角度、角速度和施加的力矩；输出是原模型对下一步状态变化的预测误差。直观关系是：

**修正后预测 = 原模型预测 + 网络预测的误差。**

具体状态表达、归一化与离散时间步，在实现数据层时确定并解释；不能把论文中的稳定性结论直接继承到这个组合上。

第一版采用**换负载 → 收集固定数量数据 → 离线拟合 → 固定模型进行测试**。暂不做边控制边学习。C1 与 C2 使用完全相同的数据；各个负载的模型单独更新，不声称“一次训练就适应所有未知重量”。

MuJoCo 中模拟真实机械臂的对象，与控制器用于预测的模型必须分开。改变真实负载后，C0 不能偷偷读到正确质量。已知真质量的模型只可另列为参考上界。

先只改变重量。若 C1 已经最好，这就是合理结论；待导师反馈后，再决定是否增加摩擦误差等更复杂问题，不为让网络获胜临时换题。

**2026-10-15 对上一段的修订。** M3 发现，只改重量时真实机械臂和模型只差一个参数，C1 估准后就等于参考上界，C2 从结构上不可能更好；这不是实验结果，而是设定决定的。因此在任何 C1、C2 结果出来之前，加入了质心偏移（W2）和关节摩擦（W3）两种 C1 表达不了的误差。只改重量的设定（W1）保留在实验里，C1 在 W1 获胜的结果照常报告。这一改动没有看过任何方法的比较结果，不属于「为让网络获胜换题」。

## 5. 参考论文：谁的工作，为什么读

以下作者关系已在论文页面核查。“名单关联”指当前候选导师是作者之一，不表示论文发表时就在悉大，也不表示该导师目前有 MPhil 名额。

### 核心阅读：先读三篇的相关部分

| 论文 | 名单关联 | 具体读什么／采用什么 |
|---|---|---|
| **Nagabandi 等，Neural Network Dynamics for Model-Based Deep Reinforcement Learning with Model-Free Fine-Tuning**，[论文](https://arxiv.org/abs/1708.02596) | **不是现有推荐导师名单的论文**；作者包括 Nagabandi、Kahn、Fearing、Levine | 第一篇入门：怎样从运动数据训练预测模型，再用 MPC 选动作。先读模型学习和模型控制部分；不复现后续 model-free 微调。它不是本项目“残差修正”的完整出处 |
| **Shi 等，Neural Lander: Stable Drone Landing Control using Learned Dynamics，ICRA 2019**，[论文](https://arxiv.org/abs/1811.08027) | **不是现有推荐导师名单的论文** | 学习如何用神经网络补充未建模的物理作用。它研究无人机着陆，采用不同控制设计；我们借鉴“物理模型＋学习修正”的思路，不声称复现其系统或继承其稳定性证明 |
| **Ian Abraham 等，Model-Based Generalization Under Parameter Uncertainty Using Path Integral Control，RA-L 2020**，[论文](https://arxiv.org/abs/2006.03106) | **是：Ian Abraham 为第一作者**，在你的悉大候选名单内 | 理解参数不确定时机器人控制为什么会失败、怎样考虑不确定性。先读问题设定、方法概览、实验；它是导师关联与研究问题参考，不是 C2 的直接算法来源 |

阅读顺序按上述顺序，每篇先能回答三件事：解决什么问题、与前一种方法有什么不同、哪些结论依赖假设。agent 负责解释相关段落和公式，你负责用自己的话复述，并在代码/画面中找到对应部分。

### 暂存的进阶阅读：不是开工前提

[Chua 等，PETS，NeurIPS 2018](https://arxiv.org/abs/1805.12114)：用多个概率运动模型表示预测的不确定性。不是当前推荐导师名单的论文。等单模型实验完成后，再理解“模型不知道自己会不会错”这一问题；不在首版实现完整 PETS。

以上是学习骨架，不是全面文献综述。形成申请报告前，再结合最终实验问题核查直接相关工作，并精选一篇目标导师近期论文。参考不是把几篇算法拼成一个所谓新方法；报告应分别注明“复现、借鉴、自己新增的实验设计”。

## 6. 和哪些申请方向有关

- **机器人：** 建模、机械臂运动、执行控制与可视化。
- **控制：** 模型误差、反馈、预测控制、力矩限制。

## 8. 验收与时间预算

第一阶段只承诺做小例子：出现可操作的机械臂画面，你能改变角度、目标和负载并解释区别。安装与首个展示预算约 1–2 次协作，每次约 1–2 小时；依赖或渲染问题可能延长，不作保证。

完整项目粗估 6–8 个有效工作周、每周约 8–12 小时，含基础学习可能更久。它与 B 不应各占一份完整的每周预算；先做 B 的可视化理解和 C 的入门场景，再选择当周重点。

研究交付至少包括：三方法对比、目标误差曲线、数据量—性能曲线、未见轨迹测试、计算耗时及失败案例。训练/验证/测试按轨迹划分，不能把相邻帧随机拆开后宣称泛化。每种方法使用相同任务、数据、动作限制和合理调参预算。

不以“网络必须最好”为验收标准。若预测误差减少却没有改善控制，也要保存和解释这个结果。若 MPC 基础迟迟不稳定，先交 PD 与负载影响的学习演示，把研究比较顺延。
